# project-3 — Todo List

A React + TypeScript + Vite todo list app, served by nginx.

## Features
- Add, complete, edit (double-click) and delete tasks
- Filter by All / Active / Completed, toggle all, clear completed
- Todos are saved in the browser's localStorage

## Development
```sh
npm install
npm run dev
```

## Deployment
Pushing to `dev` deploys the preview environment; merging to `main` deploys live.
